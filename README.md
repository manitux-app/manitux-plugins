# Manitux Eklenti Deposu

Bu depo, [Manitux](https://github.com/manitux-app/manitux) için bir eklenti koleksiyonu içerir.

Repo adresi:

```text
https://raw.githubusercontent.com/manitux-app/manitux-plugins/main/repo.json
```

Kısa kod: `manitrepo`

## Eklenti geliştiricileri için repo hazırlığı

Yeni eklenti geliştirmek için başlangıç noktası [PluginTemplate](PluginTemplate/README.md) projesidir. Proje adını değiştirme, build alma, plugin metadata alanlarını doldurma, HTTP/HTML yardımcılarını kullanma, video kaynaklarını çözümleme ve yayın metadata dosyasını hazırlama adımları PluginTemplate README'sinde anlatılır.
