# Manitux Plugin Repository

This repository contains a collection of plugins for [Manitux](https://github.com/manitux-app/manitux).

Repository URL:

```text
https://raw.githubusercontent.com/manitux-app/manitux-plugins/main/repo.json
```

Short code: `manitrepo`

## Repository Setup for Plugin Developers

Use [PluginTemplate](PluginTemplate/README_en.md) as the starting point for new plugin development. The PluginTemplate README explains how to rename the project, build it, fill plugin metadata, use the HTTP/HTML helpers, resolve video sources, and prepare the publish metadata file.
